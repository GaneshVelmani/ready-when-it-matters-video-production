# Male Character — Production Package

**Status: DESIGN REFERENCES + PRELIMINARY CUTOUTS ONLY. NOT RIGGING-READY.**

This directory is intended for the approved male character's animation assets.

## Reference scope
The working package contains:
- consolidated character design sheet;
- turnaround reference panel;
- facial expression reference panel;
- head, face and torso reference panel;
- arm and leg segmentation reference panels;
- hand pose, boot view and accessory reference panels;
- preliminary V2 cutouts and an OpenRaster working project.

## Important limitations
The approved source character is a flattened front-facing image. It does not contain authentic hidden surfaces or independently authored rear/side views, facial variants, hand poses, or boot angles. Cropped panels are visual references, not isolated production layers.

The preliminary V2 cutouts are first-pass masks and require cleanup and reconstruction. Do not use them as final rig layers.

## Acceptance criteria
1. Every required body part and variant is an individual transparent PNG, not a crop from a contact sheet.
2. Rig parts use a common canvas and include pivot/overlap guidance.
3. Joint rotation tests show no transparent gaps.
4. Face, costume, proportions and palette match the approved master.
5. Turnaround and variants are checked against the approved master.
6. The layered project opens in Krita and the rig is tested in the target animation tool.

## Source package
The complete working package should be delivered as a ZIP alongside this documentation. Large binary image assets are not included in this documentation-only commit.
